# Experiment 1 & 2 - Social Media Dashboard

## Overview

This project combines Experiment 1 and Experiment 2 of the Full Stack-II laboratory.

The application is a React-based Social Media Dashboard that allows users to compose posts, manage drafts, and implement centralized state management using Redux Toolkit.

## Features

- Compose posts for Twitter, LinkedIn, and Instagram
- Platform-specific character limits
- Save, edit, and delete drafts
- Filter drafts by platform
- Centralized state management using Redux Toolkit
- Memoized selectors using Reselect
- State normalization using Entity Adapter
- Asynchronous state handling with createAsyncThunk

## Technologies Used

- React
- Vite
- Redux Toolkit
- React Redux
- Reselect
- HTML
- CSS
- JavaScript

## Installation
